# Hamdabir brand assets

The company build of this fork ships as **Hamdabir** (Persian: همدبیر, Arabic script: همدبير).
"Dabir" is the old Persian word for a scribe or secretary; "ham-" means "alongside". The mark is a
speech bubble with right-aligned written lines (a call being written down), a coral recording dot,
and a teal check (the call was read and scored).

| File | Use |
| --- | --- |
| `hamdabir-icon.svg` | App icon, avatars, favicons |
| `hamdabir-logo.svg` | Logo on light backgrounds (Persian wordmark + Latin name) |
| `hamdabir-logo-dark.svg` | Logo on dark backgrounds |

Colours: ink `#16245C`, teal `#14B8A6`, coral `#FB7185`, muted `#5B6B8C`, white `#FFFFFF`.
Wordmark font: Vazirmatn (SIL OFL 1.1), converted to outlines, so no font is needed to show it.

Only the user-facing name changed. The package id (`com.baba.callvault`), file names, storage folders,
diagnostics and the GPL copyright lines ("The CallVault Authors") stay as they are, so updates install
over existing builds and recordings carry over.
